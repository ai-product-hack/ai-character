# Face mocap authoring

Локальный инструмент записывает 52 коэффициента MediaPipe Face Landmarker с
веб-камеры, позволяет обрезать и зациклить дубль и показывает результат сразу
на боевой GLB-модели. Камера нужна только во время авторинга; в демо она не
используется.

## Запуск

Из корня репозитория:

    python3 tools/mocap/serve.py

Откройте `http://localhost:8092/tools/mocap/` в Chrome и разрешите доступ к
камере. Модель Face Landmarker, WASM и JavaScript-пакет уже лежат локально;
интернет после установки зависимостей не нужен.

## Как записывать

1. Выберите имя клипа и включите камеру. Дождитесь статуса «лицо найдено».
2. Поставьте лицо нейтрально, нажмите «записать», затем мягко войдите в
   выражение. Держите его 3–6 секунд; в начале и конце оставьте примерно по
   полсекунды одной позы, чтобы петля склеивалась незаметно.
3. Остановите запись. Ползунками уберите подготовку и выход из роли. Кнопка
   «просмотр» зацикливает выбранный участок на самой модели.
4. Нажмите «сохранить в avatar/clips». Сервер принимает только безопасное имя
   и пишет JSON строго в `avatar/clips/`.

Нужный набор: `neutral`, `skeptical`, `pressing`, `warming`, `impressed`, затем
короткие `nod-agreement`, `raised-brow`, `slight-doubt`. Для кивка держите лицо
спокойным и кивайте из шеи; вместе с 52 коэффициентами сохраняется относительный
поворот головы.

## Формат

JSON хранит полный сырой дубль: список каналов и кадры `{tMs, weights, head}`.
`weights` соответствует `channels`, `head` — относительные градусы
`[pitch, yaw, roll]`. Рот намеренно не удаляется из файла: исходник остаётся
пригодным для повторной обработки. Рантайм эмоций отбрасывает все каналы, не
принадлежащие зоне `emotion` в `avatar/src/zones.js`.

Предпросмотр дополнительно показывает записанные `eyeLook*`, чтобы было видно,
что Face Landmarker отслеживает направление зрачков. Это только контроль
захвата: в боевом аватаре эмоция не управляет взглядом, там глаза наводятся на
пользователя отдельным слоем микроповедения.

Если запись уже есть, её можно загрузить через выбор JSON в панели и заново
обрезать или просмотреть. Захват не отправляет видео или коэффициенты в сеть.

## Как заменить временные idle-клипы тела на Mixamo

Для скачивания Mixamo нужен Adobe ID, поэтому репозиторий не притворяется, что
временные процедурные кривые являются лицензированными ассетами. После входа:

1. В Mixamo выберите три спокойные анимации без ходьбы и широких жестов:
   перенос веса, лёгкий разворот корпуса и небольшой shoulder settle.
2. Скачайте каждую как FBX, 30 FPS, `Without Skin`, по возможности `In Place`.
3. Откройте `http://localhost:8092/tools/mocap/mixamo.html`, выберите одно из
   имён `weight-shift / torso-turn / shoulder-settle`, загрузите FBX и
   сохраните. Страница заменит соответствующий JSON в `avatar/body-clips/`.
4. Перезагрузите `avatar/dev/` и тумблером `body idle` сравните движение с
   замороженной позой. Если движение отвлекает, уменьшите `weight` нужного
   клипа в `avatar/behavior.config.json`.

Импортёр берёт локальное движение относительно первого кадра и пропускает
только `Hips`, `Spine`, `Spine1`, `LeftArm`, `RightArm`. Даже если FBX содержит
анимацию головы, `Neck` и `Head` в рантайм не попадут.
