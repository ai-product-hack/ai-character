# R6 — эхо и голосовое перебивание в браузере

    ./run.sh          # поднимает http://localhost:8060 и открывает страницу

Прогнать 4 ячейки (echoCancellation true/false × WebAudio/`<audio>`) на наушниках,
затем переключить системный вывод на колонки и повторить — 8 ячеек.
Сырые результаты пишутся в `../results/r6_echo.jsonl` (пофреймовые RMS включены).
Ключ чтения: `leak_db` < 6 — AEC гасит наш выход, перебивание возможно.
